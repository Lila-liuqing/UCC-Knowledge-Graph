# 理解当代中国 · 术语知识图谱

面向政治、经济、文化、教育、公共服务与生态文明等主题的双语术语检索和关系浏览网站。

## 主要功能

- 中文词条、英文译名和编号的实时检索
- 主题模块与节点类型筛选
- 点击节点查看规范译名、语料来源、翻译说明与关联词条
- 图谱拖拽、缩放、邻接高亮和局部关系聚焦
- 桌面端与移动端响应式布局

## 本地运行

该项目是静态网站。由于页面需要读取 `data.json`，请通过本地网页服务器访问，不要直接双击打开 `index.html`。

例如在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署

仓库可直接使用 GitHub Pages 部署。入口文件为 `index.html`，无需构建步骤。
